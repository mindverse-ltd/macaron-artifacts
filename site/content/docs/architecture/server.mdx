---
title: Server
description: The local Node server that owns sessions, Profiles, pairing, artifacts, and native harness turns.
---

`createArtifactsServer` in `artifacts/src/server/index.ts` creates the single local HTTP server. The default launcher binds the UI and API to `127.0.0.1:43860`; development uses a separate Vite port and production serves the built WebUI from the same process.

## Responsibilities

- `SessionStore` persists conversation records and complete message journals under `MACARON_DATA_DIR`.
- `ActiveConversation` owns one running turn, cancellation, reconnectable streaming, and approval callbacks.
- `HarnessAdapter` implementations connect Claude Code, Codex, OpenCode, pi, Hermes, and OpenClaw to the shared AI SDK UI-message stream.
- `ProfileStore` keeps private credentials and harness configuration locally, returns only redacted public settings, and resolves configuration at turn start.
- `MetadataTasks` generates titles and follow-up suggestions on disposable native branches after the main response.
- `ArtifactObserver` watches `.artifacts` files and serves Canvas source and relative modules inside the selected workspace.
- `PairingManager` issues one-time hosted-WebUI grants while keeping the native API loopback-only.

## Request flow

The browser uses JSON endpoints for sessions, Profiles, harness discovery, artifacts, files, and approvals. A chat POST returns an AI SDK UI-message stream; a reconnect GET attaches to the same active turn. Explicit **Stop** aborts native work. Disconnecting the browser only detaches its stream, so a refresh can reconnect without restarting the turn.

Every turn captures its resolved Profile before the first native call. Editing a Profile takes effect on the next turn; the current turn and its metadata fork retain the captured configuration. Session-level model overrides affect only that conversation.

## Pairing and security

The server accepts same-origin local requests on loopback. `--pair` enables a hosted WebUI origin to claim a short-lived, one-time code and receive an origin-bound Bearer grant. Pairing does not expose an arbitrary remote bind; for an SSH host, forward the loopback port with OpenSSH and pair the forwarded address.

Generated React is trusted local code. File capabilities are restricted to `.artifacts` below the selected workspace, with path normalization and symlink checks. Credentials stay in the local Profile store and never enter browser preferences, conversation files, or stream journals.
